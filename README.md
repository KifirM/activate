
# Mail Monitor — Activate

Публичный репозиторий с файлом активации для приложения **Mail Monitor**.

## 📌 Назначение

Приложение Mail Monitor периодически обращается к файлу активации в этом
репозитории, чтобы проверить доступность мониторинга.

Если файл доступен и содержит корректное значение — мониторинг считается
разрешённым. Если файл недоступен или значение не соответствует ожидаемому —
мониторинг блокируется.

## 📄 Файл активации

 `activate.json`  Основной файл проверки доступности мониторинга |

## 🔧 Формат файла

Пример содержимого `activate.json`:

```json
{
  "active": true,
  "message": ""
}
```

Поля:
- `active` — флаг доступности мониторинга (`true` / `false`).
- `message` — опциональное сообщение, которое может отображаться пользователю
  (например, при отключении мониторинга).
