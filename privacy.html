Политика конфиденциальности
Mail Monitor

Дата редакции: 23.09.2026

1. Назначение приложения

Mail Monitor предназначено для подключения пользователя к указанному им XIMSS-почтовому серверу, мониторинга непрочитанных сообщений и показа локальных уведомлений.

2. Какие данные используются

Пользователь может указать:

  • адрес XIMSS-сервера;
  • логин;
  • пароль.

Для работы приложения также локально сохраняются служебные сведения: текущий статус мониторинга, последнее значение количества непрочитанных сообщений и UID писем, для которых уже было показано уведомление.

3. Где хранятся данные

Адрес сервера и логин сохраняются локально в хранилище приложения Android.

Пароль сохраняется локально в защищённом хранилище Android Keystore через зашифрованное хранилище приложения.

Приложение не передаёт введённый пароль разработчику.

4. Куда передаются данные

Логин и пароль передаются только на XIMSS-сервер, который указан пользователем, для авторизации и работы с почтовым ящиком.

Приложение также обращается к публичному файлу активации GitHub для проверки доступности мониторинга.

5. Уведомления

Приложение может создавать локальные уведомления о новых непрочитанных письмах и об изменении количества непрочитанных сообщений.

6. Аналитика и реклама

В текущей версии сторонние рекламные и аналитические SDK не используются.

7. Передача третьим лицам

Разработчик не передаёт логин и пароль третьим лицам. Работа с почтовым ящиком выполняется непосредственно с сервером, указанным пользователем.

8. Изменения политики

Политика может обновляться при изменении функциональности приложения. Дата редакции указывается в начале документа.
